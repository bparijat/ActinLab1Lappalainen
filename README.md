Descriptions of the ImageJ macros and how to use them can be found in the first few lines as comments. In-line comments should explain the workings...
Macro_FilamentAnalysis_withAlignmentEstimation - Uses ImageJ's Ridge Detection plugin to segment stress fibers. The macro performs some pre-processing steps to make the images more amenable for Ridge Detection to work better. Can work on multi-channel image stacks.
Macro_LineProfileAllChannels_wNorm-Cor-FHT - Performs Auto-correlation and Cross-correlation on intensity profiles from line ROIs.
Macro_StabilizeIMAGEs_inTimelapse - To manually stabilize a point/multiple points in timelapse movies by mouse-clicks.
Macro_getAVGdistance_LineROI_fromMASKedge - To get the average distance of a line ROI from an area ROI
